# Phase 17 — Tracking QA Automation

The master tracking regression command composes purchase security, schema versioning, attribution, internal/test exclusion, lifecycle metrics, retention cleanup, product URL identity, deploy readiness, and TikTok safety audits.

## Command

`npm run qa:master-tracking`

Child audit failures are preserved in the machine-readable result so release governance can block on the actual contract rather than a documentation-only claim.
